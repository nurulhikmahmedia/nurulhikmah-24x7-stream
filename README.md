# Nurul Hikmah 24/7 Stream
Prototype: direct MP4 URL -> FFmpeg loop -> YouTube RTMPS.

Render Environment Variables:
- VIDEO_URL = direct HTTPS URL to MP4
- YOUTUBE_STREAM_KEY = YouTube Live stream key (keep secret)

Render Free is for testing and is not guaranteed to remain online 24/7.
Never put the YouTube stream key in this public repository.
